# Instalación de Python

En caso de que no tengas instalado y configurado Python en tu sistema aquí
están unas guías acorde a tu sistema operativo. En estos casos utilizaremos la
línea de comandos. El sistema operativo que recomiendo para programar en Python
es Linux o macOS. También se puede utilizar Windows pero hay algunos programas
o librerías que corren nativamente en Linux o macOS y no tienen soporte oficial
en Windows. Por ejemlo, Redis.

## Windows

En caso de que no tengas instalada la aplicación Terminal te recomiendo que la instales
cuanto antes desde la [Microsoft Store](https://apps.microsoft.com/detail/9n0dx20hk701). Esta es una versión más moderna y rápida que el tradicional programa de Command Prompt (console.exe). Además esta versión es de [codigo abierto](https://github.com/microsoft/terminal).
La instalación funciona para las versiones 10 y 11 de Windows.

Vamos a utilzar la herramienta WinGet, esta herramienta nos permite
gestionar aplicaciones desde la línea de comandos. Esto es similar a
los programas apt en debian o brew en macOS.
