# Introducción a Python

En estos días a principios del 2025, Python es el lenguaje de programación más
popular, según el índice de [TIOBE](https://www.tiobe.com), quienes además le han dado el premio de
"lenguaje de programación del año 2024". El premio se otorga al lenguaje con el
mayor incremento de calificación en un año, creciendo un 9.3% solo
en el año 2024 [https://www.tiobe.com/tiobe-index/]. Actualmente, Pyhton no
tiene rival en varios campos de la computación, por ejemplo, análisis de datos,
aprendizaje automático y desarrollo de aplicaciones de aprendizaje profundo.
Una razón de este éxito es debido a que aprender el lenguaje resulta práctico,
ya que es interpretado, lo que nos permite probar el código sin necesidad de
compilarlo. Algunas desventajas son su bajo rendimiento en comparación con
lenguajes compilados como C++ o Rust y que muchos de los errores en el código
suceden al momento de ejecución.

En mi caso, llegué al lenguaje atraído por sus frameworks para el desarrollo de
aplicaciones web a principios de los dos mil, por ejemplo el framework
[CherryPy](https://cherrypy.dev/) con el que desarrollé algunas aplicaciones
web, de una manera muy fácil para la época. Ya después surgieron [Django]() y
[FastAPI]() más utilizados en la actualidad. Aunque probé otros lenguajes de
scripts populares para esas tareas como [tcl](), [PHP]() y ya después [Ruby](),
la sintaxis de Python se me hizo más amigable y fácil de entender. Con el paso
del tiempo surgieron muchas librerías y servicios innovadores para el
desarrollo de aplicaciones científicas que no encontraba en los otros
lenguajes, por lo que lo fui utilizando para otro tipo de proyectos. Por
ejemplo, en 2008, Python era el único lenguaje utilizado por Google App Engine,
permitiendo de una manera muy sencilla de ejecutar código de alto desempeño en
la nube de manera automática. Otro proyecto interesante fue
[PiCloud](https://www.crunchbase.com/organization/picloud), este servicio,
permitía de una manera transparente ejecutar código de alto desempeño en la
nube a partir de código ejecutado localmente, solamente importando una
librería. Era la primera aproximación a lo que hoy es computación
[Serverless](https://es.wikipedia.org/wiki/Serverless_computing).

Igualmente, otros programadores llegarán a interesarse por Python por algún
proyecto o problema que quieren atacar, y para el cual ya existe una librería o
código escrito que soluciona gran parte del problema central. Tal vez sea
utilizar un [API](https://platform.openai.com/docs/quickstart) de inteligencia
artificial generativa, [procesar
imágenes](https://pillow.readthedocs.io/en/latest/index.html) para subirlas a
un servicio en la
[nube](https://boto3.amazonaws.com/v1/documentation/api/latest/guide/s3-uploading-files.html),
programar un [rastreador web](https://www.crummy.com/software/BeautifulSoup/),
o un simulador utilizando [ecuaciones diferenciales
ordinaras](https://docs.scipy.org/doc/scipy/reference/generated/scipy.integrate.odeint.htm).
Python tiene librerías y ejemplos para este tipo de problemas.

Si este es tu caso, este libro está pensado con en tí, el objetivo es permitir
a programadores ponerse al día de manera rápida con el lenguaje y servir como
guía para resolver distintos tipos de problemas del área de ingeniería para los
que Python puede ser de gran ayuda. Para solucionar el problema o por lo menos
para crear un buen protitipo.
