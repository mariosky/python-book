# Introducción a Python

En estos días a principios del 2025, Python es lenguaje de programación más
popular, el índice TIOBE le ha dado el premio de "el lenguaje de programación
del año 2024". El premio se otorga al lenguaje con el mayor incremento de
calificación en un año, creciendo un sorprendente 9.3% solo en el año 2024
[https://www.tiobe.com/tiobe-index/]. El lenguaje es el estándar en varios
campos de la computación, por ejemplo, análisis de datos, aprendizaje
automático y desarrollo de aplicaciones. Aprender el lenguaje resulta práctico,
ya que es interpretado, lo que nos permite probar el código sin necesidad de
compilarlo. Algunas desventajas son su bajo rendimiento en comparación con
lenguajes compilados como C++ o Rust y que muchos de los errores en el código
suceden al momento de ejecución.

Yo en particular llegué al lenguaje atraido por sus frameworks para el
desarrollo de aplicaciones Web a pricipios de los dos mil, por ejemplo el
framework [CherryPy](https://cherrypy.dev/) con el que desarrollé algunas
aplicaciones web, ya después surgieron [Django]() y [FastAPI]() más utilizados
en la actualidad. Aunque probé otros lenguajes de scripts populares para esas
tareas como [tcl](), [PHP]() y ya después [Ruby](), la sintáxis de Python se me
hizo más amigable y fácil de entender. También con el paso del tiempo surgieron
muchas librerías y servicios innovadores para el desarrollo de aplicaciones
científicas que no encontraba en los otros lenguajes por lo que lo fui
utilizando para otros proyectos. Por ejemplo, en 2008, Python era el único
lenguaje utilizado por Google App Engine, permitiendo de una manera muy
sencilla de ejecutar código en la nube. Otro proyecto interesante fue
[PiCloud](https://www.crunchbase.com/organization/picloud), esté servicio
permitía de una manera transparente ejecutar código de alto desempeño en la
nube a partir de código ejecutado localmente, era una primera aproximación a lo
que hoy es computación
[Serverless](https://es.wikipedia.org/wiki/Serverless_computing). Igualmente,
otros programadores llegarán a interesarse por el lenguaje por algún proyecto
que quieren atacar, y para el cual ya existe una librería o código escrito que
soluciona gran parte del problema tienen. Tal vez sea utilizar un
[API](https://platform.openai.com/docs/quickstart) de inteligencia artificial
generativa, [procesar
imágenes](https://pillow.readthedocs.io/en/latest/index.html) para subirlas a
un servicio en la
[nube](https://boto3.amazonaws.com/v1/documentation/api/latest/guide/s3-uploading-files.html),
programar un [rastreador web](https://www.crummy.com/software/BeautifulSoup/),
o un simulador utilizando [ecuaciones diferenciales
ordinaras](https://docs.scipy.org/doc/scipy/reference/generated/scipy.integrate.odeint.htm).
Python tiene librerías y ejemplos para este tipo de problemas. En este caso este
libro también tiene este objetivo, permitir a programadores aprender de manera
rápida el lenguaje y servir como guía para resolver distintos tipos de problemas
del área de ingeniería para los que Python puede ser de gran ayuda, para
solucionar el problema o por lo menos para crear un buen protitipo.
